# Phase 3 — Apps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agents (and people) can create, publish, and run **apps** — single-file HTML applications stored in the `kyoube` database that read and write the company's Data tables through a sandboxed `window.kyoube` SDK — and users open them from an **Apps** page inside Paperclip.

**Architecture:** Apps live in `kyoube_meta.apps` / `kyoube_meta.app_versions` and are managed by an `AppService` layered on Phase 2's `DataService`. The plugin UI renders a published app in an opaque-origin `<iframe sandbox srcdoc>` with a strict CSP; the injected SDK talks to the host page over `postMessage`, and the host page forwards data calls to worker actions (`apps.data.*`) that enforce `viewer level ∩ app-declared table access`. Agents author apps through tools, REST routes, and a managed skill that documents the SDK.

**Tech Stack:** same as Phase 2 plus a tiny build-time-inlined SDK package (`packages/kyoube-app-sdk`, esbuild IIFE) and `useHostLocation` for nested routes (`/:company/apps/<slug>`).

**Spec:** `docs/superpowers/specs/2026-09-05-kyoubeai-architecture-design.md` §8.4, §10, §13 Phase 3. Builds on Phases 0–2.

> **Post-execution notes (2026-09-07).** Phase 3 is implemented; where the code differs from the snippets below, the code and the rulings P3-R1..R22 recorded during execution are authoritative. Substantive deviations: the iframe sandbox is exactly `allow-scripts allow-forms allow-modals` — no `allow-popups` (P3-R2) — and the injected CSP adds `base-uri 'none'`; the v1 SDK surface is the plan's (`data.subscribe`, `ui.confirm`, `theme`, and "Preview draft" from spec §8.4 are deferred to the roadmap; the plugin's `typecheck`/`build` scripts build the SDK first and inline its IIFE through an esbuild `define` (P3-R6); the shared tool runtime preserves Phase 2's missing-context guard, generic internal-error body, and no-params logging, and the apps routes share the data routes' 403/500 bodies (P3-R7); there is no module-level `currentApps` — the `AppService` is a closure variable and both route families answer 503 until setup (P3-R8); `usePluginData` params are memoised, actions are read through refs, and no `eslint-disable` comments exist (P3-R9); archived app slugs are reusable because archive is terminal — a partial unique index on live rows and live-only by-slug lookups (P3-R10); rollback re-runs publish's declared-tables check, so a version whose tables were dropped cannot be re-pointed to (P3-R11); the protocol guards reject an own `__proto__` key (P3-R12); the message handler lives in `bridge.ts` where it is unit-tested with fake events, and the source panel hides write/schema controls below the viewer's level (P3-R13); the skill and docs state that the CSP, not the sandbox, blocks network access, `data:`/`blob:` images and `data:` fonts are allowed, `notes` is capped at 2,000 characters, and the runtime image asserts the inlined SDK and the apps migration (P3-R14/R15). **From the final review:** `buildSrcdoc` no longer splices into the app's `<head>` at all — it always prepends our `<head>` (CSP meta + SDK) right after an optional leading doctype, because the tokenizer closes comments at `--!>`, `<!-->`, and `<!--->` where the plan's "inert prefix" regex did not, which let a crafted document run script before the policy (P3-R16); bridge and page errors are read from the host's plain-object rejections (`PluginBridgeError { code, message, details }` — upstream's `usePluginAction` never throws an `Error`), which the plan's `split(":")` helper and the terminal plugin's `error-code.ts` both mishandle as "[object Object]" (P3-R17; the terminal fix is a Phase 4 carry-over); a frame that navigates itself is stopped — any `load` after the first kills the bridge and unmounts the iframe — because the sandbox cannot stop self-navigation and the same WindowProxy would otherwise keep speaking the protocol (P3-R18); every runtime data method, validator, and the write gate are unit-proven (P3-R19); `apps_create`/`apps_update` no longer echo the source (P3-R20); `notes` is validated in the actions, lifecycle audit rows carry `appId`, `apps.status` has a CHECK constraint, and the docs state that `eval` is unavailable, that form submissions need `preventDefault()`, and that navigation stops the app (P3-R21). **Known residual at phase close (P3-R22):** `buildSrcdoc`'s doctype match uses JavaScript's `\s`, which accepts Unicode whitespace (U+00A0, U+000B, U+2028, U+3000, or a BOM after a newline) that the HTML tokenizer treats as content, so such a byte before `<!doctype>` still pushes the injected `<head>` into the body and voids the CSP (verified in a headless Blink parser by the re-review); the fix — the HTML ASCII-whitespace class `[\t\n\f\r ]` plus browser-verified tests — is the first item of Phase 4's hardening pass, which runs before any release work. Manual acceptance (Task 6 Step 4, plus the final review's checks: a `--!>` document still cannot `fetch`, a self-navigating app is stopped, error toasts show the worker's message) is still owed. Deferred minors and Phase 4 carry-overs are recorded in the Phase 4 plan's Task 5 note.

## Global Constraints

- Same toolchain rules as Phases 0–2. Plugin stays `kyoube.apps` (version bumps to `0.3.0`).
- App slug: `^[a-z][a-z0-9-]{1,48}$`, unique per company. App source ≤ 2 MiB (2 097 152 bytes), UTF-8, one HTML document.
- App manifest (stored with each version): `{ name, slug, description?, icon?, tables: [{ name, access: "read" | "readwrite" }], surfaces?: ["page"] }`; `tables` must reference existing Data tables at publish time.
- Permissions: gallery/run → `read`; create/update draft → `write`; publish/rollback/archive → `schema`. At runtime an app's data call is allowed only if the viewer's level allows the operation **and** the app declared the table with sufficient access (`readwrite` for writes).
- Sandbox: `<iframe sandbox="allow-scripts allow-forms allow-modals allow-popups" srcdoc=…>` — never `allow-same-origin`; injected CSP `default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data: blob:; font-src data:; connect-src 'none'; form-action 'none'`.
- postMessage protocol version `1`: request `{ kyoube: 1, id, method, params }`; response `{ kyoube: 1, id, result }` or `{ kyoube: 1, id, error: { code, message } }`; host → app on load `{ kyoube: 1, event: "ready", context }`. The host only accepts messages whose `source === iframe.contentWindow`.
- SDK surface (`window.kyoube`): `ready(): Promise<Context>`, `context`, `data.query(table, spec)`, `data.get(table, id)`, `data.count(table, where?)`, `data.insert(table, rows)`, `data.update(table, target, patch)`, `data.delete(table, target)`, `data.describe(table)`, `ui.toast(title, tone?)`, `ui.openApp(slug)`; `Context = { companyId, viewer: { id, name, level }, app: { slug, name, version }, tables: string[] }`.
- New tool names: `apps_list, apps_get, apps_create, apps_update, apps_publish, apps_rollback, apps_archive`; new routes under `/apps`; action keys `apps.list/get/create/update/publish/rollback/archive` and `apps.data.query/get/count/insert/update/delete/describe`.

```ts
import { z } from "zod";
import { DataError } from "../data/errors.js";
import { assertIdentifier } from "../data/identifiers.js";

export const APP_SLUG_RE = /^[a-z][a-z0-9-]{1,48}$/;
export const MAX_APP_SOURCE_BYTES = 2 * 1024 * 1024;

export interface AppManifest {
  name: string;
  slug: string;
  description: string | null;
  icon: string | null;
  tables: Array<{ name: string; access: "read" | "readwrite" }>;
  surfaces: Array<"page">;
}

const schema = z.object({
  name: z.string().trim().min(1).max(120),
  slug: z.string().regex(APP_SLUG_RE, "slug must match ^[a-z][a-z0-9-]{1,48}$"),
  description: z.string().max(2000).nullable().optional(),
  icon: z.string().max(16).nullable().optional(),
  tables: z.array(z.object({ name: z.string(), access: z.enum(["read", "readwrite"]).optional() })).max(50),
  surfaces: z.array(z.enum(["page"])).optional(),
});

export function validateAppManifest(raw: unknown): AppManifest {
  const parsed = schema.safeParse(raw);
  if (!parsed.success) throw new DataError("invalid", `invalid app manifest: ${parsed.error.issues.map((issue) => `${issue.path.join(".") || "manifest"} ${issue.message}`).join("; ")}`);
  const seen = new Set<string>();
  const tables = parsed.data.tables.map((table) => {
    const name = assertIdentifier(table.name, "app table");
    if (seen.has(name)) throw new DataError("invalid", `duplicate table "${name}" in app manifest`);
    seen.add(name);
    return { name, access: table.access ?? ("read" as const) };
  });
  return { name: parsed.data.name, slug: parsed.data.slug, description: parsed.data.description ?? null, icon: parsed.data.icon ?? null, tables, surfaces: parsed.data.surfaces?.length ? parsed.data.surfaces : ["page"] };
}

export function assertAppSource(source: unknown): string {
  if (typeof source !== "string") throw new DataError("invalid", "app source must be a string");
  if (Buffer.byteLength(source, "utf8") > MAX_APP_SOURCE_BYTES) throw new DataError("limit", "app source must be at most 2 MiB");
  if (!/<(html|body|script)[\s>]/i.test(source)) throw new DataError("invalid", "app source must be an HTML document");
  return source;
}
```

`plugins/kyoube-apps/src/apps/store.ts`:
```ts
import type { Pool } from "pg";
import { DataError } from "../data/errors.js";
import type { AppManifest } from "./manifest.js";

export interface AppVersion { id: string; version: number; manifest: AppManifest; source: string; createdByKind: string; createdById: string | null; notes: string | null; createdAt: string }
export interface AppRecord { id: string; companyId: string; slug: string; name: string; description: string | null; icon: string | null; status: "draft" | "published" | "archived"; currentVersion: number | null; latestVersion: number; createdAt: string; updatedAt: string }

interface AppRow { id: string; company_id: string; slug: string; name: string; description: string | null; icon: string | null; status: AppRecord["status"]; current_version: number | null; latest_version: number; created_at: Date; updated_at: Date }
interface VersionRow { id: string; version: number; manifest: AppManifest; source: string; created_by_kind: string; created_by_id: string | null; notes: string | null; created_at: Date }

const APP_COLUMNS = "id, company_id, slug, name, description, icon, status, current_version, latest_version, created_at, updated_at";
const VERSION_COLUMNS = "id, version, manifest, source, created_by_kind, created_by_id, notes, created_at";

function toApp(row: AppRow): AppRecord {
  return { id: row.id, companyId: row.company_id, slug: row.slug, name: row.name, description: row.description, icon: row.icon, status: row.status, currentVersion: row.current_version, latestVersion: row.latest_version, createdAt: row.created_at.toISOString(), updatedAt: row.updated_at.toISOString() };
}
function toVersion(row: VersionRow): AppVersion {
  return { id: row.id, version: row.version, manifest: row.manifest, source: row.source, createdByKind: row.created_by_kind, createdById: row.created_by_id, notes: row.notes, createdAt: row.created_at.toISOString() };
}

export class AppStore {
  constructor(private readonly pool: Pool) {}

  async list(companyId: string, opts: { includeArchived?: boolean } = {}): Promise<AppRecord[]> {
    const result = await this.pool.query<AppRow>(
      `SELECT ${APP_COLUMNS} FROM kyoube_meta.apps WHERE company_id = $1 ${opts.includeArchived ? "" : "AND status <> 'archived'"} ORDER BY name`,
      [companyId],
    );
    return result.rows.map(toApp);
  }

  async get(companyId: string, slug: string): Promise<AppRecord | null> {
    const result = await this.pool.query<AppRow>(`SELECT ${APP_COLUMNS} FROM kyoube_meta.apps WHERE company_id = $1 AND slug = $2`, [companyId, slug]);
    return result.rows[0] ? toApp(result.rows[0]) : null;
  }

  async getVersion(companyId: string, slug: string, version: number | "current" | "latest"): Promise<AppVersion | null> {
    const app = await this.get(companyId, slug);
    if (!app) return null;
    const number = version === "current" ? app.currentVersion : version === "latest" ? app.latestVersion : version;
    if (number === null || number <= 0) return null;
    const result = await this.pool.query<VersionRow>(`SELECT ${VERSION_COLUMNS} FROM kyoube_meta.app_versions WHERE app_id = $1 AND version = $2`, [app.id, number]);
    return result.rows[0] ? toVersion(result.rows[0]) : null;
  }

  async create(companyId: string, manifest: AppManifest, source: string, by: { kind: string; id: string | null }, notes: string | null = null): Promise<{ app: AppRecord; version: AppVersion }> {
    if (await this.get(companyId, manifest.slug)) throw new DataError("conflict", `app "${manifest.slug}" already exists`);
    const client = await this.pool.connect();
    try {
      await client.query("BEGIN");
      const app = await client.query<AppRow>(
        `INSERT INTO kyoube_meta.apps (company_id, slug, name, description, icon, latest_version) VALUES ($1, $2, $3, $4, $5, 1) RETURNING ${APP_COLUMNS}`,
        [companyId, manifest.slug, manifest.name, manifest.description, manifest.icon],
      );
      const version = await client.query<VersionRow>(
        `INSERT INTO kyoube_meta.app_versions (app_id, version, manifest, source, created_by_kind, created_by_id, notes) VALUES ($1, 1, $2, $3, $4, $5, $6) RETURNING ${VERSION_COLUMNS}`,
        [app.rows[0]!.id, JSON.stringify(manifest), source, by.kind, by.id, notes],
      );
      await client.query("COMMIT");
      return { app: toApp(app.rows[0]!), version: toVersion(version.rows[0]!) };
    } catch (error) {
      await client.query("ROLLBACK").catch(() => {});
      throw error;
    } finally {
      client.release();
    }
  }

  async addVersion(companyId: string, slug: string, manifest: AppManifest, source: string, by: { kind: string; id: string | null }, notes: string | null = null): Promise<AppVersion> {
    const app = await this.require(companyId, slug);
    const client = await this.pool.connect();
    try {
      await client.query("BEGIN");
      const bumped = await client.query<{ latest_version: number }>(
        "UPDATE kyoube_meta.apps SET latest_version = latest_version + 1, name = $2, description = $3, icon = $4, updated_at = now() WHERE id = $1 RETURNING latest_version",
        [app.id, manifest.name, manifest.description, manifest.icon],
      );
      const version = await client.query<VersionRow>(
        `INSERT INTO kyoube_meta.app_versions (app_id, version, manifest, source, created_by_kind, created_by_id, notes) VALUES ($1, $2, $3, $4, $5, $6, $7) RETURNING ${VERSION_COLUMNS}`,
        [app.id, bumped.rows[0]!.latest_version, JSON.stringify(manifest), source, by.kind, by.id, notes],
      );
      await client.query("COMMIT");
      return toVersion(version.rows[0]!);
    } catch (error) {
      await client.query("ROLLBACK").catch(() => {});
      throw error;
    } finally {
      client.release();
    }
  }

  async setCurrent(companyId: string, slug: string, version: number): Promise<AppRecord> {
    const app = await this.require(companyId, slug);
    const exists = await this.pool.query("SELECT 1 FROM kyoube_meta.app_versions WHERE app_id = $1 AND version = $2", [app.id, version]);
    if (!exists.rowCount) throw new DataError("not_found", `app "${slug}" has no version ${version}`);

      `UPDATE kyoube_meta.apps SET current_version = $2, status = 'published', updated_at = now() WHERE id = $1 RETURNING ${APP_COLUMNS}`,
      [app.id, version],
    );
    return toApp(result.rows[0]!);
  }

  async setStatus(companyId: string, slug: string, status: AppRecord["status"]): Promise<AppRecord> {
    const app = await this.require(companyId, slug);
    const result = await this.pool.query<AppRow>(`UPDATE kyoube_meta.apps SET status = $2, updated_at = now() WHERE id = $1 RETURNING ${APP_COLUMNS}`, [app.id, status]);
    return toApp(result.rows[0]!);
  }

  private async require(companyId: string, slug: string): Promise<AppRecord> {
    const app = await this.get(companyId, slug);
    if (!app) throw new DataError("not_found", `app "${slug}" not found`);
    return app;
  }
}

import type { Pool } from "pg";
import { recordAudit } from "../data/audit.js";
import { DataError } from "../data/errors.js";
import { assertLevel, levelAllows, type AccessLevel, type DataActor } from "../data/permissions.js";
import type { DataService, MutationEvent } from "../data/service.js";
import { assertAppSource, validateAppManifest, type AppManifest } from "./manifest.js";
import { AppStore, type AppRecord, type AppVersion } from "./store.js";

export interface AppContext {
  companyId: string;
  viewer: { id: string | null; name: string; level: AccessLevel };
  app: { slug: string; name: string; version: number };
  tables: string[];
}

export type RuntimeMethod = "query" | "get" | "count" | "describe" | "insert" | "update" | "delete";
const RUNTIME_METHODS: readonly RuntimeMethod[] = ["query", "get", "count", "describe", "insert", "update", "delete"];
const WRITE_METHODS: readonly RuntimeMethod[] = ["insert", "update", "delete"];

function str(params: Record<string, unknown>, key: string): string {
  const value = params[key];
  if (typeof value !== "string" || value.length === 0) throw new DataError("invalid", `${key} is required`);
  return value;
}

export class AppService {
  private readonly store: AppStore;
  private readonly pool: Pool;
  private readonly data: DataService;
  private readonly onMutation: ((event: MutationEvent) => Promise<void>) | undefined;

  constructor(deps: { pool: Pool; data: DataService; onMutation?: (event: MutationEvent) => Promise<void> }) {
    this.pool = deps.pool;
    this.data = deps.data;
    this.store = new AppStore(deps.pool);
    this.onMutation = deps.onMutation;
  }

  async list(companyId: string, actor: DataActor): Promise<AppRecord[]> {
    const level = await this.level(companyId, actor, "read", "list apps");
    const all = await this.store.list(companyId);
    return levelAllows(level, "write") ? all : all.filter((app) => app.status === "published");
  }

  async get(companyId: string, actor: DataActor, slug: string, version: number | "current" | "latest" = "latest"): Promise<{ app: AppRecord; version: AppVersion | null }> {
    const level = await this.level(companyId, actor, "read", "read an app");
    const app = await this.store.get(companyId, slug);
    if (!app || (app.status !== "published" && !levelAllows(level, "write"))) throw new DataError("not_found", `app "${slug}" not found`);
    return { app, version: await this.store.getVersion(companyId, slug, version) };
  }

  async create(companyId: string, actor: DataActor, rawManifest: unknown, rawSource: unknown, notes: string | null = null): Promise<{ app: AppRecord; version: AppVersion }> {
    await this.level(companyId, actor, "write", "create an app");
    const manifest = validateAppManifest(rawManifest);
    const source = assertAppSource(rawSource);
    const created = await this.store.create(companyId, manifest, source, { kind: actor.kind, id: actor.id }, notes);
    await this.audit(companyId, actor, "app_create", manifest.slug, { version: 1 }, `created app ${manifest.slug} (draft)`);
    return created;
  }

  async update(companyId: string, actor: DataActor, slug: string, rawManifest: unknown, rawSource: unknown, notes: string | null = null): Promise<AppVersion> {
    await this.level(companyId, actor, "write", "update an app");
    const manifest = validateAppManifest(rawManifest);
    if (manifest.slug !== slug) throw new DataError("invalid", "the manifest slug must match the app being updated");
    const source = assertAppSource(rawSource);
    const version = await this.store.addVersion(companyId, slug, manifest, source, { kind: actor.kind, id: actor.id }, notes);
    await this.audit(companyId, actor, "app_update", slug, { version: version.version }, `saved app ${slug} version ${version.version} (draft)`);
    return version;
  }

  async publish(companyId: string, actor: DataActor, slug: string, version?: number): Promise<AppRecord> {
    await this.level(companyId, actor, "schema", "publish an app");
    const target = await this.store.getVersion(companyId, slug, version ?? "latest");
    if (!target) throw new DataError("not_found", `app "${slug}" has no version ${version ?? "latest"}`);
    for (const table of target.manifest.tables) await this.data.describeTable(companyId, actor, table.name);
    const app = await this.store.setCurrent(companyId, slug, target.version);
    await this.audit(companyId, actor, "app_publish", slug, { version: target.version }, `published app ${slug} version ${target.version}`);
    return app;
  }

  async rollback(companyId: string, actor: DataActor, slug: string, version: number): Promise<AppRecord> {
    await this.level(companyId, actor, "schema", "roll back an app");
    const app = await this.store.setCurrent(companyId, slug, version);
    await this.audit(companyId, actor, "app_rollback", slug, { version }, `rolled app ${slug} back to version ${version}`);
    return app;
  }

  async archive(companyId: string, actor: DataActor, slug: string): Promise<AppRecord> {
    await this.level(companyId, actor, "schema", "archive an app");
    const app = await this.store.setStatus(companyId, slug, "archived");
    await this.audit(companyId, actor, "app_archive", slug, {}, `archived app ${slug}`);
    return app;
  }

  async runtime(companyId: string, actor: DataActor, slug: string, viewerName: string): Promise<{ context: AppContext; source: string }> {
    const level = await this.level(companyId, actor, "read", "open an app");
    const app = await this.store.get(companyId, slug);
    const version = app?.status === "published" ? await this.store.getVersion(companyId, slug, "current") : null;
    if (!app || !version) throw new DataError("not_found", `app "${slug}" is not published`);
    return {
      context: { companyId, viewer: { id: actor.id, name: viewerName, level }, app: { slug, name: app.name, version: version.version }, tables: version.manifest.tables.map((table) => table.name) },
      source: version.source,
    };
  }

  async runtimeData(companyId: string, actor: DataActor, slug: string, method: RuntimeMethod, params: Record<string, unknown>): Promise<unknown> {
    if (!RUNTIME_METHODS.includes(method)) throw new DataError("invalid", `unknown app data method "${String(method)}"`);
    const { context } = await this.runtime(companyId, actor, slug, "");
    const version = await this.store.getVersion(companyId, slug, "current");
    const table = str(params, "table");
    const declared = version?.manifest.tables.find((entry) => entry.name === table);
    if (!declared) throw new DataError("forbidden", `app "${slug}" does not declare table "${table}"`);
    if (WRITE_METHODS.includes(method) && declared.access !== "readwrite") throw new DataError("forbidden", `app "${slug}" only has read access to "${table}"`);
    void context;
    switch (method) {
      case "describe": return this.data.describeTable(companyId, actor, table);
      case "query": return this.data.query(companyId, actor, table, { where: params.where, orderBy: params.orderBy as never, limit: params.limit as number | undefined, offset: params.offset as number | undefined, fields: params.fields as string[] | undefined });
      case "get": return this.data.get(companyId, actor, table, str(params, "id"));
      case "count": return { count: await this.data.count(companyId, actor, table, params.where) };
      case "insert": return this.data.insert(companyId, actor, table, Array.isArray(params.rows) ? params.rows : []);
      case "update": return this.data.update(companyId, actor, table, { ids: params.ids as string[] | undefined, where: params.where }, (params.patch ?? {}) as Record<string, unknown>);
      case "delete": return this.data.delete(companyId, actor, table, { ids: params.ids as string[] | undefined, where: params.where });
    }
  }

  private async level(companyId: string, actor: DataActor, op: "read" | "write" | "schema", what: string): Promise<AccessLevel> {
    const level = await this.data.levelFor(companyId, actor);
    assertLevel(level, op, what);
    return level;
  }

  private async audit(companyId: string, actor: DataActor, operation: string, slug: string, details: Record<string, unknown>, summary: string): Promise<void> {
    await recordAudit(this.pool, { companyId, actor, operation, table: null, details: { app: slug, ...details } });
    if (this.onMutation) await this.onMutation({ companyId, actor, operation, table: null, summary });
  }
}

export const ALLOWED_METHODS = ["data.query", "data.get", "data.count", "data.describe", "data.insert", "data.update", "data.delete", "ui.toast", "ui.openApp"] as const;

export interface KyoubeRequest { kyoube: 1; id: string; method: KyoubeMethod; params: Record<string, unknown> }
export interface KyoubeResponse { kyoube: 1; id: string; result?: unknown; error?: { code: string; message: string } }
export interface KyoubeReadyEvent { kyoube: 1; event: "ready"; context: unknown }

function isRecord(value: unknown): value is Record<string, unknown> {
  return typeof value === "object" && value !== null && !Array.isArray(value);
}

export function isKyoubeRequest(value: unknown): value is KyoubeRequest {
  return isRecord(value) && value.kyoube === KYOUBE_PROTOCOL && typeof value.id === "string" && typeof value.method === "string"
    && (ALLOWED_METHODS as readonly string[]).includes(value.method) && isRecord(value.params);
}

export function isKyoubeResponse(value: unknown): value is KyoubeResponse {
  return isRecord(value) && value.kyoube === KYOUBE_PROTOCOL && typeof value.id === "string" && ("result" in value || isRecord(value.error));
}

export function isKyoubeReady(value: unknown): value is KyoubeReadyEvent {
  return isRecord(value) && value.kyoube === KYOUBE_PROTOCOL && value.event === "ready";
}

interface Pending { resolve: (value: unknown) => void; reject: (error: Error) => void }

class KyoubeAppError extends Error {
  code: string;
  constructor(code: string, message: string) { super(message); this.name = "KyoubeAppError"; this.code = code; }
}

(function install() {
  if (typeof window === "undefined" || window.parent === window) return;
  const pending = new Map<string, Pending>();
  let context: unknown = null;
  const readyListeners: Array<(context: unknown) => void> = [];
  let counter = 0;

  window.addEventListener("message", (event) => {
    if (event.source !== window.parent) return;
    const message: unknown = event.data;
    if (isKyoubeReady(message)) {
      context = message.context;
      for (const listener of readyListeners.splice(0)) listener(context);
      return;
    }
    if (!isKyoubeResponse(message)) return;
    const entry = pending.get(message.id);
    if (!entry) return;
    pending.delete(message.id);
    if (message.error) entry.reject(new KyoubeAppError(message.error.code, message.error.message));
    else entry.resolve(message.result);
  });

  function call(method: KyoubeMethod, params: Record<string, unknown> = {}): Promise<unknown> {
    const id = `k${++counter}`;
    return new Promise((resolve, reject) => {
      pending.set(id, { resolve, reject });
      window.parent.postMessage({ kyoube: KYOUBE_PROTOCOL, id, method, params }, "*");
      setTimeout(() => { if (pending.delete(id)) reject(new KyoubeAppError("timeout", `${method} timed out`)); }, 30_000);
    });
  }

  const kyoube = {
    version: KYOUBE_PROTOCOL,
    get context() { return context; },
    ready(): Promise<unknown> { return context ? Promise.resolve(context) : new Promise((resolve) => readyListeners.push(resolve)); },
    data: {
      query: (table: string, spec: Record<string, unknown> = {}) => call("data.query", { ...spec, table }),
      get: (table: string, id: string) => call("data.get", { table, id }),
      count: (table: string, where?: unknown) => call("data.count", { table, where }),
      describe: (table: string) => call("data.describe", { table }),
      insert: (table: string, rows: unknown[]) => call("data.insert", { table, rows }),
      update: (table: string, target: Record<string, unknown>, patch: Record<string, unknown>) => call("data.update", { table, ...target, patch }),
      delete: (table: string, target: Record<string, unknown>) => call("data.delete", { table, ...target }),
    },
    ui: {
      toast: (title: string, tone: "info" | "success" | "warn" | "error" = "info") => call("ui.toast", { title, tone }),
      openApp: (slug: string) => call("ui.openApp", { slug }),
    },
    Error: KyoubeAppError,
  };
  Object.defineProperty(window, "kyoube", { value: Object.freeze(kyoube), writable: false, configurable: false });
  window.parent.postMessage({ kyoube: KYOUBE_PROTOCOL, id: "hello", method: "ui.toast", params: { __hello: true } }, "*");
})();
```
(The trailing `hello` message lets the host know the SDK is installed; the host replies with the `ready` event and ignores the toast because of `__hello`.)

export const APP_CSP = "default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data: blob:; font-src data:; connect-src 'none'; form-action 'none'; base-uri 'none'";

/** Prepends the CSP and the SDK to the app document so both run before any app code. */
export function buildSrcdoc(source: string, sdkJs: string): string {
  const injection = `<meta http-equiv="Content-Security-Policy" content="${APP_CSP}"><script>${sdkJs.replace(/<\/script/gi, "<\\/script")}</script>`;
  const headMatch = /<head[^>]*>/i.exec(source);
  if (headMatch) {
    const at = headMatch.index + headMatch[0].length;
    return `${source.slice(0, at)}${injection}${source.slice(at)}`;
  }
  const htmlMatch = /<html[^>]*>/i.exec(source);
  if (htmlMatch) {
    const at = htmlMatch.index + htmlMatch[0].length;
    return `${source.slice(0, at)}<head>${injection}</head>${source.slice(at)}`;
  }
  return `<head>${injection}</head>${source}`;
}

import type { KyoubeRequest } from "@kyoube/app-sdk";

export type RoutedRequest =
  | { kind: "hello" }
  | { kind: "data"; method: string; params: Record<string, unknown> }
  | { kind: "toast"; title: string; tone: string }
  | { kind: "openApp"; slug: string }
  | { kind: "reject"; code: string; message: string };

const SLUG_RE = /^[a-z][a-z0-9-]{1,48}$/;

export function routeAppRequest(request: KyoubeRequest): RoutedRequest {
  if (request.method === "ui.toast") {
    if (request.params.__hello === true) return { kind: "hello" };
    const title = request.params.title;
    if (typeof title !== "string" || title.length === 0) return { kind: "reject", code: "invalid", message: "toast needs a title" };
    const tone = typeof request.params.tone === "string" ? request.params.tone : "info";
    return { kind: "toast", title: title.slice(0, 200), tone };
  }
  if (request.method === "ui.openApp") {
    const slug = request.params.slug;
    if (typeof slug !== "string" || !SLUG_RE.test(slug)) return { kind: "reject", code: "invalid", message: "openApp needs a valid slug" };
    return { kind: "openApp", slug };
  }
  return { kind: "data", method: request.method.slice("data.".length), params: request.params };
}

export function parseAppsPath(pathname: string): { slug: string | null } {
  const segments = pathname.split("/").filter(Boolean);
  const index = segments.indexOf("apps");
  if (index === -1) return { slug: null };
  const slug = segments[index + 1];
  return { slug: slug && SLUG_RE.test(slug) ? slug : null };
}

import { useEffect, useMemo, useRef } from "react";
import { isKyoubeRequest, KYOUBE_PROTOCOL } from "@kyoube/app-sdk";
import { routeAppRequest } from "./bridge.js";
import { buildSrcdoc } from "./srcdoc.js";

export interface AppRunnerProps {
  source: string;
  context: unknown;
  onData: (method: string, params: Record<string, unknown>) => Promise<unknown>;
  onToast: (title: string, tone: string) => void;
  onOpenApp: (slug: string) => void;
}

/** Renders the app in an opaque-origin iframe and brokers postMessage calls to the worker. */
export function AppRunner(props: AppRunnerProps) {
  const frame = useRef<HTMLIFrameElement | null>(null);
  const srcdoc = useMemo(() => buildSrcdoc(props.source, __KYOUBE_APP_SDK__), [props.source]);
  const latest = useRef(props);
  latest.current = props;

  useEffect(() => {
    const handler = async (event: MessageEvent) => {
      const target = frame.current?.contentWindow;
      if (!target || event.source !== target) return;
      if (!isKyoubeRequest(event.data)) return;
      const request = event.data;
      const reply = (body: Record<string, unknown>) => target.postMessage({ kyoube: KYOUBE_PROTOCOL, id: request.id, ...body }, "*");
      const routed = routeAppRequest(request);
      switch (routed.kind) {
        case "hello":
          target.postMessage({ kyoube: KYOUBE_PROTOCOL, event: "ready", context: latest.current.context }, "*");
          return;
        case "toast":
          latest.current.onToast(routed.title, routed.tone);
          reply({ result: null });
          return;
        case "openApp":
          latest.current.onOpenApp(routed.slug);
          reply({ result: null });
          return;
        case "reject":
          reply({ error: { code: routed.code, message: routed.message } });
          return;
        case "data":
          try {
            reply({ result: await latest.current.onData(routed.method, routed.params) });
          } catch (error) {
            const message = error instanceof Error ? error.message : String(error);
            reply({ error: { code: message.split(":")[0]?.trim() ?? "error", message } });
          }
      }
    };
    window.addEventListener("message", handler);
    return () => window.removeEventListener("message", handler);
  }, []);

  return <iframe ref={frame} title="Kyoube app" sandbox="allow-scripts allow-forms allow-modals allow-popups" srcDoc={srcdoc} className="h-full min-h-[600px] w-full rounded border bg-white" />;
}

import { z } from "zod";
import { DataError } from "./data/errors.js";
import type { DataActor } from "./data/permissions.js";

export interface ToolDefinition<S> {
  name: string;
  displayName: string;
  description: string;
  schema: z.ZodTypeAny;
  run: (service: S, companyId: string, actor: DataActor, params: any) => Promise<unknown>;
}

const MAX_CONTENT_CHARS = 20_000;

export function formatToolResult(data: unknown): string {
  const text = JSON.stringify(data, null, 2) ?? "null";
  return text.length > MAX_CONTENT_CHARS ? `${text.slice(0, MAX_CONTENT_CHARS)}\n… (truncated; narrow the query or use limit/offset)` : text;
}

export function jsonSchemaFor(schema: z.ZodTypeAny): Record<string, unknown> {
  const generated = z.toJSONSchema(schema, { target: "draft-7" }) as Record<string, unknown>;
  delete generated.$schema;
  return generated;
}

export function declarationsFor<S>(definitions: ToolDefinition<S>[]): PluginToolDeclaration[] {
  return definitions.map((tool) => ({ name: tool.name, displayName: tool.displayName, description: tool.description, parametersSchema: jsonSchemaFor(tool.schema) }));
}

export function registerToolHandlers<S>(ctx: PluginContext, definitions: ToolDefinition<S>[], service: S): void {
  for (const tool of definitions) {
    ctx.tools.register(tool.name, { displayName: tool.displayName, description: tool.description, parametersSchema: jsonSchemaFor(tool.schema) }, async (params, runCtx) => {
      const parsed = tool.schema.safeParse(params ?? {});
      if (!parsed.success) {
        return { error: `invalid: ${parsed.error.issues.map((issue) => `${issue.path.join(".") || "params"} ${issue.message}`).join("; ")}` };
      }
      const actor: DataActor = { kind: "agent", id: runCtx.agentId, runId: runCtx.runId };
      try {
        const data = await tool.run(service, runCtx.companyId, actor, parsed.data);
        return { content: formatToolResult(data), data };
      } catch (error) {
        const message = error instanceof DataError ? error.message : `error: ${error instanceof Error ? error.message : String(error)}`;
        ctx.logger.warn("tool failed", { tool: tool.name, agentId: runCtx.agentId, message });
        return { error: message };
      }
    });
  }
}

import type { PluginApiRequestInput, PluginApiResponse, PluginApiRouteDeclaration } from "@paperclipai/plugin-sdk";
import { z } from "zod";
import { actorFromRequest, statusForError } from "../api-routes.js";
import { DataError } from "../data/errors.js";
import type { AppService } from "./service.js";

function route(routeKey: string, method: "GET" | "POST", path: string): PluginApiRouteDeclaration {
  return { routeKey, method, path, auth: "board-or-agent", capability: "api.routes.register", companyResolution: method === "GET" ? { from: "query", key: "companyId" } : { from: "body", key: "companyId" } };
}

export const APP_API_ROUTES: PluginApiRouteDeclaration[] = [
  route("apps.list", "GET", "/apps"),
  route("apps.create", "POST", "/apps"),
  route("apps.get", "GET", "/apps/:slug"),
  route("apps.update", "POST", "/apps/:slug"),
  route("apps.publish", "POST", "/apps/:slug/publish"),
  route("apps.rollback", "POST", "/apps/:slug/rollback"),
  route("apps.archive", "POST", "/apps/:slug/archive"),
];

const manifestSchema = z.object({ name: z.string(), slug: z.string(), description: z.string().nullable().optional(), icon: z.string().nullable().optional(), tables: z.array(z.object({ name: z.string(), access: z.enum(["read", "readwrite"]).optional() })), surfaces: z.array(z.enum(["page"])).optional() });
const createBody = z.object({ manifest: manifestSchema, source: z.string().min(1), notes: z.string().nullable().optional() });
const publishBody = z.object({ version: z.number().int().optional() });
const rollbackBody = z.object({ version: z.number().int() });

function parse<T>(schema: z.ZodType<T>, body: unknown): T {
  const parsed = schema.safeParse(body ?? {});
  if (!parsed.success) throw new DataError("invalid", parsed.error.issues.map((issue) => `${issue.path.join(".") || "body"} ${issue.message}`).join("; "));
  return parsed.data;
}

function slugOf(input: PluginApiRequestInput): string {
  const slug = input.params.slug;
  if (!slug) throw new DataError("invalid", "slug is required");
  return slug;
}

export async function handleAppsApiRequest(apps: AppService, input: PluginApiRequestInput): Promise<PluginApiResponse | null> {
  if (!input.routeKey.startsWith("apps.")) return null;
  const companyId = input.companyId;
  const actor = actorFromRequest(input);
  try {
    let body: unknown;
    switch (input.routeKey) {
      case "apps.list": body = await apps.list(companyId, actor); break;
      case "apps.create": { const b = parse(createBody, input.body); body = await apps.create(companyId, actor, b.manifest, b.source, b.notes ?? null); break; }
      case "apps.get": {
        const raw = typeof input.query.version === "string" ? input.query.version : undefined;
        const version = raw === undefined ? "latest" : raw === "current" || raw === "latest" ? raw : Number(raw);
        if (typeof version === "number" && !Number.isInteger(version)) throw new DataError("invalid", "version must be an integer, current, or latest");
        body = await apps.get(companyId, actor, slugOf(input), version);
        break;
      }
      case "apps.update": { const b = parse(createBody, input.body); body = await apps.update(companyId, actor, slugOf(input), b.manifest, b.source, b.notes ?? null); break; }
      case "apps.publish": { const b = parse(publishBody, input.body); body = await apps.publish(companyId, actor, slugOf(input), b.version); break; }
      case "apps.rollback": { const b = parse(rollbackBody, input.body); body = await apps.rollback(companyId, actor, slugOf(input), b.version); break; }
      case "apps.archive": body = await apps.archive(companyId, actor, slugOf(input)); break;
      default: return { status: 404, body: { error: `unknown route ${input.routeKey}`, code: "not_found" } };
    }
    return { status: 200, body };
  } catch (error) {
    const message = error instanceof DataError ? error.message : `error: ${error instanceof Error ? error.message : String(error)}`;
    return { status: statusForError(error), body: { error: message, code: error instanceof DataError ? error.code : "error" } };
  }
}

---
name: kyoube-apps
description: Build, update, and publish KyoubeAI apps — single-file HTML applications that run inside the Paperclip UI and use the company's Kyoube Data tables through window.kyoube. Use when a task asks for a CRM, tracker, dashboard, form, or any internal tool over company data.

# Kyoube Apps

An app is **one HTML document** (inline CSS and JavaScript, no external URLs — the sandbox blocks all
network access) plus a **manifest** that declares which Data tables it uses. Users open apps at
`/<company>/apps/<slug>`. Apps run in a sandboxed iframe; the only way to reach data is `window.kyoube`.

## Workflow

1. Design or reuse tables with the `kyoube-data` skill (`data_list_tables`, `data_create_table`).
2. `apps_create` with a manifest and the full source. This makes **draft version 1**.
3. Test in the browser? You cannot — ask the user to open the app; or reason carefully and keep the UI simple.
4. `apps_publish` (needs schema access; if you only have write access, ask an admin to publish).
5. Iterate with `apps_update` (new draft version) → `apps_publish`. `apps_rollback` restores an earlier version.

## Manifest

```json
{ "name": "Sales CRM", "slug": "sales-crm", "icon": "📇", "description": "Contacts and deals",
  "tables": [ { "name": "contacts", "access": "readwrite" }, { "name": "deals", "access": "readwrite" } ] }
```
`access` is `read` (default) or `readwrite`. A call on an undeclared table is rejected. The viewer's own
level still applies: a `viewer` can never write, whatever the app declares.

## window.kyoube (injected before your code runs)

```ts
await kyoube.ready()                       // → { companyId, viewer: { id, name, level }, app: { slug, name, version }, tables }
kyoube.data.query(table, { where?, orderBy?, limit?, offset?, fields? })   // → { rows, limit, offset }
kyoube.data.get(table, id)                 // → row | null
kyoube.data.count(table, where?)           // → { count }
kyoube.data.describe(table)                // → { fields: [{ name, kind, required, options }] }
kyoube.data.insert(table, rows)            // → created rows (validated by field kind)
kyoube.data.update(table, { ids } | { where }, patch)   // → { affected, rows }
kyoube.data.delete(table, { ids } | { where })          // → { affected }
kyoube.ui.toast(title, "success" | "error" | "info")
kyoube.ui.openApp(slug)
```
`where` grammar: `{ field, op, value }` with `eq neq gt gte lt lte in contains starts_with is_null is_not_null`,
combined with `{ and: [...] }`, `{ or: [...] }`, `{ not: {...} }`. Errors are thrown as `kyoube.Error` with
`code` (`forbidden`, `invalid`, `not_found`, `limit`). Every row has `id`, `created_at`, `updated_at`.

## Rules for the source

- Start with `<!doctype html>`; put CSS in `<style>` and JS in `<script>` — no `src=`, `href=` to the network, no `fetch`.
- Use `kyoube.ready()` before the first data call; render loading and error states; keep lists paged (`limit` ≤ 200).
- Use semantic HTML and plain CSS; it must be readable on a 1024px-wide panel and in dark mode (`prefers-color-scheme`).
- Never store secrets or tokens in the app; never assume other companies' data exists.
- Keep the whole file under 2 MiB (usually well under 100 KB).

## Minimal example

```html

```markdown
## Security model

Apps run in an iframe with `sandbox="allow-scripts allow-forms allow-modals allow-popups"` — no `allow-same-origin` — so they have an opaque origin: no cookies, no Paperclip API, no storage shared with the host. A Content-Security-Policy meta tag blocks every network request and remote script. The only channel is `postMessage` to the host page, which validates the sender, restricts methods to the `window.kyoube` surface, and forwards data calls to the plugin worker with **the viewer's identity**. The worker applies the viewer's access level and the app's declared tables before touching the database. An app can therefore never do more than the person using it could do on the Data page.
```

Add to `README.md` under a new `## Apps` heading:
```markdown
## Apps

Apps are single-file HTML applications that run inside the Paperclip UI (`/<company>/apps`) and use the company's Data tables through an injected `window.kyoube` SDK. Agents build and publish them with the `kyoube.apps:apps_*` tools, guided by the **Kyoube Apps** managed skill; people can review source and versions, publish, and roll back from the app page. Apps run sandboxed (opaque origin + strict CSP) and can never exceed the permissions of the person using them. See `docs/apps.md`.
